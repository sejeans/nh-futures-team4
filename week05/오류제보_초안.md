**[제보] 해외 현재가: 종목 2개를 한 번에 요청하면 오류 코드 없이 HTTP 200과 빈 본문이 옵니다**

**팀:** team-04
**환경:** 모의 (apidemo.futures.co.kr), 2026-11-16(월) 14:51, Python 3.12 (urllib)
**대상:** 해외 현재가 `POST /trade/v1/overseas/price`

**재현 절차**
1. 토큰 발급
2. 종목 1개씩 요청
`{"Iccurs1":[{"iccurs1_exch_cd":"FCME","iccurs1_sym":"ZNZ26"}]}`
`{"Iccurs1":[{"iccurs1_exch_cd":"FCME","iccurs1_sym":"ZFZ26"}]}`
3. 같은 두 종목을 한 요청에 넣어 요청
`{"Iccurs1":[{"iccurs1_exch_cd":"FCME","iccurs1_sym":"ZNZ26"},{"iccurs1_exch_cd":"FCME","iccurs1_sym":"ZFZ26"}]}`
4. 2~3번을 3회 반복

**기대 결과**
두 종목의 시세가 `Occurs1`에 2줄로 반환됨. 여러 종목 조회를 지원하지 않는다면 요청 건수 오류 코드와 메시지가 반환됨

**실제 결과**
- 1종목 요청: HTTP 200, `Occurs1` 1줄에 시세 정상 (6/6회)
- 2종목 요청: HTTP 200, 응답 본문이 빈 문자열 (3/3회). JSON이 아니어서 오류 코드와 메시지가 없음
- 11/01에 처음 같은 현상을 확인했고, 11/16에 재현함

**팀:** team-04
**환경:** 모의 (apidemo.futures.co.kr), 2026-11-16(월) 14:51, Python 3.12 (urllib)
**대상:** 해외 예수금 조회 `POST /trade/v1/overseas/deposit`

**재현 절차**
1. 토큰 발급
2. 아래 세 요청을 순서대로 호출하고 3회 반복
`{"biz_dt":"20261116","cur_cd":"USD","cvs_div":"1"}`
`{"biz_dt":"","cur_cd":"USD","cvs_div":"1"}`
`{"cur_cd":"USD","cvs_div":"1"}` (`biz_dt` 키 없음)
